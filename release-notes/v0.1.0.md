# vmemo v0.1.0

## English

`vmemo` is a read-only command-line tool for listing, searching, showing, exporting, and diagnosing Voice Memos recordings. This release does not rename, delete, or otherwise modify Voice Memos data. It supports the exact production contract of macOS 26 with Voice Memos build 1380; other operating systems or builds fail closed.

The release asset is `vmemo-0.1.0-macos-universal2.pkg`. It installs the signed `vmemo` executable at `/usr/local/bin/vmemo` and contains both `arm64` and `x86_64` slices. The PKG is intended to be Developer ID signed, notarized, and stapled before publication. `SHA256SUMS` and `provenance.json` accompany the PKG.

The tool may require the user to grant macOS access to the Voice Memos library when the read-only commands need it. It does not request Accessibility or Apple Events permission and has no write permission workflow.
