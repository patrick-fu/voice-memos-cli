# vmemo v0.1.2

## English

`vmemo` v0.1.2 is the first supported one-line binary installation release. It keeps the read-only commands and macOS 26 / Voice Memos build 1380 production contract unchanged.

```sh
curl -fsSL https://raw.githubusercontent.com/patrick-fu/voice-memos-cli/v0.1.2/install.sh | sh
```

The installer downloads the immutable Release's Apple-notarized universal2 ZIP, validates its SHA-256, exact archive shape, Developer ID identity, secure timestamp, Hardened Runtime, online notarization requirement, architectures, version, and provenance, then atomically installs `~/.local/bin/vmemo` without sudo. v0.1.2 supersedes v0.1.1, whose installer incorrectly used `plutil -lint` for JSON metadata and therefore stopped safely before installation.

## 中文

`vmemo` v0.1.2 是首个受支持的一行二进制安装版本。只读命令面以及仅支持 macOS 26 / Voice Memos build 1380 的生产契约保持不变。

```sh
curl -fsSL https://raw.githubusercontent.com/patrick-fu/voice-memos-cli/v0.1.2/install.sh | sh
```

安装脚本从不可变 Release 下载 Apple 公证的 universal2 ZIP，依次校验 SHA-256、精确压缩包结构、Developer ID 身份、安全时间戳、Hardened Runtime、在线公证要求、架构、版本与 provenance，最后无需 sudo、原子安装到 `~/.local/bin/vmemo`。v0.1.2 取代 v0.1.1；后者错误地用 `plutil -lint` 检查 JSON metadata，因此会在安装前安全退出。
