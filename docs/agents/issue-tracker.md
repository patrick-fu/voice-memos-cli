# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, comment, label, and close issues with `gh issue`.
- Infer the repository from `git remote -v`.
- PRs are not part of the triage request surface.
- Publishing to the issue tracker means creating a GitHub issue.

## Wayfinding operations

- The map is an issue labelled `wayfinder:map`.
- Decision tickets are GitHub sub-issues labelled `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or `wayfinder:task`.
- Use native GitHub issue dependencies when available.
- Claim work by assigning the issue to the driving developer.
- Resolve by commenting with the answer, closing the ticket, and adding a linked gist to the map.
