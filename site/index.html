安心

FAQ

常见问题

支持哪些系统？

v0.1.2 只支持 macOS 26 与 Voice Memos build 1380。其他系统或版本会安全提示不支持。

第一次使用为什么会要求权限？

读取录音时，macOS 可能要求你授予“完全磁盘访问权限”或容器权限。只有你能授权，vmemo 不会替你改设置。

录音会被传到网上吗？

不会。vmemo 只在本地运行，导出也只是把一份 .m4a 复制到你选择的位置。

它会修改、删除或转写录音吗？

不会。vmemo 只能查看、搜索、确认和导出副本，导出的副本不会改动原文件。

装在哪里？

默认安装到 ~/.local/bin/vmemo。脚本不会修改 shell 配置；如果这个目录不在 PATH 中，脚本会提示需要运行的命令。
