核心支柱Core Pillars

只读、可验证、可被 agent 消费Read-only, verifiable, agent-ready

vmemo 不为 Voice Memos 增加写入面。它 snapshot 资料库、校验已知 schema，然后只返回活跃录音或一份新的 .m4a 副本。 vmemo does not add a write surface to Voice Memos. It snapshots the library, validates a known schema, then returns only active recordings or a new .m4a copy.

安全只读沙箱Read-only sandbox

隔离 SQLite snapshot，约束资产路径，排除「最近删除」。不使用辅助功能、Apple Events 或私有 entitlement。 Isolated SQLite snapshots, constrained asset paths, and Recently Deleted excluded. No Accessibility, Apple Events, or private entitlements.

毫秒级 SQLite 索引Millisecond SQLite index

list / search / show 走只读 snapshot 元数据，不扫描音频。search 只做标题的大小写不敏感包含匹配。 list, search, and show read snapshot metadata, not audio. search is case-insensitive title containment only.

原声 .m4a 导出Original .m4a export

把本地 regular .m4a 复制到一个尚不存在的目标路径。源录音不变；复制中源文件变化则失败。 Copies a local regular .m4a to a destination that must not already exist. The source recording is unchanged; a changing source fails closed.

Developer ID 签名、Hardened Runtime、Apple 公证的 universal2 ZIP。安装脚本不需要 sudo，也不弹安装器。 Developer ID signed, Hardened Runtime, Apple-notarized universal2 ZIP. The installer needs no sudo and no GUI package.

Agent & Pipeline

稳定的 JSON Envelope 与退出码A stable JSON envelope and exit codes

每个命令都接受 --json。Agent 应先跑 doctor --json，仅在 data.status == "ready" 后继续，并原样使用返回的 opaque ID。 Every command accepts --json. Agents should run doctor --json first, continue only when data.status == "ready", and reuse the returned opaque ID exactly.

JSON Envelope

{
  "version": 1,
  "status": "ok",
  "data": {}
}

失败时 status 为 error，并带 error.code / error.message。doctor 即使是 blocked / incomplete 也把报告写到 stdout。 Failures use status: "error" with error.code and error.message. doctor always writes its report to stdout, even when blocked or incomplete.

退出码Exit codes

Code 含义Meaning
0成功；doctor 为 readySuccess; doctor is ready
2用法或参数错误Usage or argument error
3运行/输出错误Operational or output error
4安全或适配器阻断Safety or adapter block
5部分或不完整报告Partial or incomplete report

推荐流程Recommended pipeline

  1. 1vmemo doctor --json
  2. 2vmemo list --json / search --query
  3. 3vmemo show --id （可选）(optional)
  4. 4vmemo export --id --output-path
id="$(vmemo search --query "standup" --json | jq -r '.data.recordings[0].id')"
vmemo export --id "$id" --output-path "$HOME/Downloads/standup.m4a" --json

jq 管道jq pipeline

把 envelope 交给 jq。不要把 title 写进日志；ID 必须原样回传。 Pipe the envelope to jq. Do not log titles; pass IDs back exactly as returned. 

vmemo list --json \
  | jq -r '.data.recordings[] | [.id, .title] | @tsv'

FAQ

兼容性与常见问题Compatibility and common questions

支持哪些系统？ Which systems are supported?

v0.1.2 的生产数据路径只支持 macOS 26 与 Voice Memos build 1380。其他系统或 build 会安全拒绝。macOS 15 可用于构建和 fail-closed 测试，但不是受支持的生产路径。 v0.1.2 production data access supports macOS 26 with Voice Memos build 1380 only. Other systems or builds fail closed. macOS 15 can build and exercise fail-closed tests, but it is not a supported production path.

为什么会要求完全磁盘访问权限？ Why does it ask for Full Disk Access?

Voice Memos 的 group container 可能需要 FDA 或容器权限。安装本身只写 ~/.local/bin，不需要 FDA；读取录音时 macOS 才会询问。只有你能在「系统设置 → 隐私与安全性」中授权。 The Voice Memos group container may require Full Disk Access or another container permission. Installing only writes ~/.local/bin and does not need FDA; macOS may ask later when recordings are read. Only you can grant it in System Settings → Privacy & Security.

录音会被传到网上吗？ Are recordings sent anywhere?

不会。vmemo 只在本地运行。导出只是把一份 .m4a 复制到你选择的位置。标题只出现在你主动请求的 stdout 里。 No. vmemo runs locally. Export copies an .m4a to a location you choose. Titles appear only in the stdout payload you requested.

它会修改、删除或转写录音吗？ Does it modify, delete, or transcribe recordings?

不会。没有 rename / delete，也没有转写或 UI 自动化。export 只创建用户拥有的副本。 No. There is no rename or delete, and no transcription or UI automation. export only creates a user-owned copy.

如何验证签名和公证？ How do I verify signing and notarization?

用上面的 codesign 与 lipo 命令。期望看到 Developer ID Application、Team ID 9N7UKH59LC，以及 arm64 x86_64。 Use the codesign and lipo commands above. Expect Developer ID Application, Team ID 9N7UKH59LC, and arm64 x86_64.

装在哪里？需要 sudo 吗？ Where does it install, and is sudo required?

默认安装到 ~/.local/bin/vmemo，不需要 sudo。脚本不会改 shell 配置；若该目录不在 PATH 中，它会打印应执行的命令。可用 VMEMO_INSTALL_DIR 换目录。 It installs to ~/.local/bin/vmemo by default, with no sudo. The script does not edit shell config; if that directory is not on PATH, it prints the command to add it. Use VMEMO_INSTALL_DIR for another directory.
