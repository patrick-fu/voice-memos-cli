Agent 工作流

先准入，再拿 ID，最后只复制。

每个命令都有稳定 exit code 与 JSON v1 envelope。不要做 UI 自动化，也不要从标题或路径推导 ID。

  1. 01
    doctor

    先验证系统、App、library、schema 与签名。未 ready 就停止。

  2. 02
    list / search

    列出 active recordings，或按标题做大小写不敏感搜索，拿到 opaque ID。

  3. 03
    show / export

    确认目标，或把本地 .m4a 复制到一个尚不存在的路径。源录音保持原样。

安全边界

能读，不等于能改。

vmemo 用临时 SQLite snapshot 读取，环境或 schema 不匹配就 fail closed。不需要 Accessibility，不发送 Apple Events，也不使用 mutation token。

  • 没有 rename / delete / 转写命令
  • 不直接写 Voice Memos 数据库、asset 或 CloudKit
  • 生产数据路径仅 macOS 26 + Voice Memos build 1380
  • 录音标题只出现在调用方请求的 stdout

安装

装进 ~/.local/bin/vmemo，不要 sudo。

安装脚本从不可变 GitHub Release 拉取 Apple 公证的 universal2 ZIP，逐项校验后再原子写入。不弹安装器，也不改你的 shell 配置。

$ 
curl -fsSL https://raw.githubusercontent.com/patrick-fu/voice-memos-cli/v0.1.2/install.sh | sh
签名与公证
Developer ID Application 签名、安全时间戳、Hardened Runtime；codesign 在线校验 Apple 公证票据。
发布物
不可变 Release；ZIP 与 SHA256SUMS 一致；arm64 + x86_64；版本与 provenance 对齐。
PATH
默认 ~/.local/bin/vmemo。若该目录不在 PATH 中，脚本只打印应执行的命令。换目录用 VMEMO_INSTALL_DIR，选版本用 VMEMO_VERSION。
权限
安装本身不需要 Full Disk Access。读取录音时你可能仍需在「系统设置 › 隐私与安全性」中授权；只有用户能授予，vmemo doctor 会报告状态。
次要路径 · 源码构建无签名
git clone https://github.com/patrick-fu/voice-memos-cli.git
cd voice-memos-cli
swift build -c release
.build/release/vmemo doctor
.build/release/vmemo list --json

生产数据路径只支持 macOS 26 与 Voice Memos build 1380。其他系统与 build 会安全地返回 unsupported。
