面向 macOS 的只读工具

让 agent 安全地读取你的语音备忘录。

vmemo 是稳定、可脚本化的 CLI：列出、搜索、查看和导出 Voice Memos；不改名、不删除，也不触碰私有数据写入。

为 agent 而生

不是一段脆弱的 UI 自动化。

每个命令都有明确的 stdout/stderr 边界、稳定 exit code 与 JSON v1 envelope，让你的自动化可以做正确的下一步。

  1. 01
    doctor

    先验证系统、App、library 与 schema；未就绪时停止。

  2. 02
    list / search

    获取 opaque ID；搜索只匹配录音标题。

  3. 03
    show / export

    确认目标或导出 .m4a 副本，源录音保持原样。

小而完整的工具面

五个命令，清晰的承诺。

list

列出 active recordings。

search

按标题进行大小写不敏感搜索。

show

通过 opaque ID 确认一条录音。

export

复制到不存在的目标路径，仅支持 .m4a。

doctor

在读数据前做只读、隔离的准入检查。

安全是产品边界

能读取，不等于能改写。

vmemo 对不匹配的环境和 schema 直接拒绝；读取时使用临时 SQLite snapshot。它不需要 Accessibility，不发送 Apple Events，也不使用任何 mutation token。

  • ✓不支持 rename 或 delete
  • ✓不直接写入 Voice Memos 数据库、asset 或 CloudKit
  • ✓未通过精确契约时 fail closed
  • ✓录音标题仅出现在调用方请求的 stdout

开始使用

一条命令，装进用户目录。

安装脚本从不可变 GitHub Release 下载 Apple 公证的 universal2 ZIP，逐项校验后再把 vmemo 原子写入 ~/.local/bin/vmemo。不需要 sudo，也不会弹出安装器。

推荐路径 · 一行安装
curl -fsSL https://raw.githubusercontent.com/patrick-fu/voice-memos-cli/v0.1.1/install.sh | sh

安装前的校验

Developer ID 签名 & Apple 公证

  • ✓Release 不可变，ZIP 校验和匹配 SHA256SUMS
  • ✓Developer ID Application 签名、安全时间戳、Hardened Runtime
  • ✓spctl 在线校验 Apple 公证票据
  • ✓arm64 与 x86_64 双 slice，版本与 provenance 一致

兼容性、PATH 与访问

生产数据路径只支持 macOS 26 与 Voice Memos build 1380。其他系统与 build 会安全地返回 unsupported。

默认安装到 ~/.local/bin/vmemo；若它不在 PATH 中，脚本只提示应执行的命令，不会改动 shell 配置。换目录用 VMEMO_INSTALL_DIR，选版本用 VMEMO_VERSION。

安装本身不需要 Full Disk Access。读取语音备忘录时你可能仍需在「系统设置 > 隐私与安全性」中授权；仅用户可以授予该权限，vmemo doctor 会报告状态。

隐私说明

你的录音不会经过本网站。

这是纯静态文档站：没有分析脚本、追踪像素、外部字体或 CDN。vmemo 在本地运行；请让调用它的 agent 避免将录音标题、搜索词或含标题的路径写入日志。
